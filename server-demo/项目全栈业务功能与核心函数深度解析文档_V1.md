# server-demo 历史 DongBoot 基线解析文档 V1（归档）

> **归档说明：本文描述的是改造前的 DongBoot/京东内部中间件脚手架，不是当前 JoyCue 本地 Demo 的运行基线。** 当前代码已经切换为标准 Spring Boot 2.7、MyBatis 与本地 H2，并移除了 JSF、DUCC、DongDAL、DongGuardian、DongThread、DongContext 等运行依赖。当前实现、接口和启动方式请以根目录 `README.md`、`ARCHITECTURE.md` 及本目录 `ARCHITECTURE.md` 为准；本文仅用于追溯原始课件结构。

## 一、项目全局业务画像

### 1.1 项目定位

**server-demo** 是京东内部 **DongBoot 脚手架**（dong-boot-dependencies 1.1.1）的标准示例项目，定位为**京东技术栈组件集成演示模板**。它不是一个面向终端用户的业务系统，而是一个面向京东开发者的"技术脚手架学习沙盒"，展示如何在 DDD 分层架构下集成京东6大内部中间件。

### 1.2 业务域划分

| 业务域 | 英文名 | 职责 |
|--------|--------|------|
| 订单域 | Order Domain | 演示 JSF RPC、DongDAL 数据库、DongGuardian 限流、DongContext 上下文、DUCC 配置中心 |
| 商品域 | Item Domain | 演示 DongDAL 数据库基础 CRUD |
| 并行域 | Parrell Domain | 演示 DongThread 三种线程池 |

### 1.3 技术栈全景

| 层级 | 技术选型 |
|------|----------|
| 框架基座 | DongBoot 1.1.1（Spring Boot 封装） |
| RPC 通信 | JSF（京东服务框架） |
| 数据访问 | DongDAL + MyBatis |
| 配置中心 | DUCC（@LafValue 注入） |
| 限流降级 | DongGuardian（@GuardianResource / API 双模式） |
| 线程管理 | DongThread（ThreadPoolExecutor / ScheduledThreadPoolExecutor / ThreadPoolTaskExecutor） |
| 全局上下文 | DongContext（GlobalTTLContext） |
| 健康检查 | DongBoot Actuator（HealthChecker） |
| Web 层 | Spring MVC（@Controller + @RequestMapping） |
| 数据转换 | 手写 Converter（6个转换器） |

### 1.4 模块架构总览

```
server-demo (parent POM)
├── server-demo-client     ← 服务契约层（JSF接口 + DTO/Param）
├── server-demo-app        ← 应用服务层（业务编排 + JSF发布 + 限流）
├── server-demo-domain     ← 领域层（领域服务 + BO + DO转换）
├── server-demo-infra-api  ← 基设施抽象层（Gateway接口 + DO）
├── server-demo-infra-impl ← 基础设施实现层（Gateway实现 + Mapper + JSF消费 + 配置）
├── server-demo-web        ← Web表现层（Controller + VO + DTO转换）
├── server-demo-common     ← 公共层（常量 + 枚举 + 异常 + 工具）
├── server-demo-main       ← 启动模块（Application + 配置文件）
└── server-demo-test       ← 测试模块
```

## 三、后端核心类与函数的逐层拆解

### 3.1 Web 表现层（server-demo-web）

#### OrderController
- **路径**: `server-demo-web/.../web/controller/OrderController.java`
- **注解**: `@Controller`, `@RequestMapping("/order")`, `@Api`
- **依赖注入**: `DuccConfiguration`, `OrderService`

| 方法 | HTTP路由 | 功能 | 调用链 |
|------|----------|------|--------|
| `hello(name)` | `/order/hello` | 测试服务是否启动 | 直接返回字符串 |
| `getOrderFromRpc(id)` | `/order/getfromrpc` | 测试JSF RPC调用 | OrderService→OrderDomainService→OrderGateway→JSF Consumer |
| `getOrderFromDb(id)` | `/order/getfromdb` | 测试DongDAL数据库 | OrderService→OrderDomainService→OrderGateway→OrderMapper |
| `contextInfo()` | `/order/contextinfo` | 测试DongContext | GlobalTTLContext.getGlobalRequestId() |
| `getDuccConfig()` | `/order/duccget` | 测试DUCC配置中心 | DuccConfiguration.getMessage() |
| `testCluster()` | `/order/testCluster` | 测试DongGuardian注解模式 | OrderService.testCluster()→@GuardianResource |
| `testCluster1()` | `/order/testCluster1` | 测试DongGuardian API模式 | OrderService.testCluster1()→DongGuardian.entry() |

#### ParrellController
- **路径**: `server-demo-web/.../web/controller/ParrellController.java`
- **注解**: `@Controller`, `@RequestMapping("/parrell")`, `@Api`

| 方法 | HTTP路由 | 功能 |
|------|----------|------|
| `getFromScheduledThreadPool(text)` | `/parrell/get` | 测试DongThread三种线程池 |

#### Web VO/Converter
- `OrderVO {id, value}` — 订单视图对象
- `Result<T> {code, data, msg}` — 通用API响应包装
- `OrderDTOConverter.convert(OrderDTO→OrderVO)` — DTO→VO转换

### 3.3 App 应用服务层（server-demo-app）

#### OrderServiceImpl
- **路径**: `server-demo-app/.../app/order/api/impl/OrderServiceImpl.java`
- **核心注解**:
  - `@Service` — Spring Bean
  - `@BootService(bindings={@BootServiceBinding(alias="${dong.jsf.demo.alias}", server={"server1"}, bindingType="jsf")})` — **JSF服务发布**
  - `@Api(value="订单服务")` — API文档
- **依赖**: `OrderDomainService`

| 方法 | 功能 | 中间件 |
|------|------|--------|
| `getFromRpc(param)` | 调用领域服务RPC查询，BO→DTO转换 | JSF |
| `getFromDb(param)` | 调用领域服务DB查询，BO→DTO转换 | DongDAL |
| `testCluster(s)` | `@GuardianResource`注解限流，fallback=helloFallback | DongGuardian |
| `helloFallback(s, ex)` | 限流降级方法，打印异常并返回提示 | DongGuardian |
| `testCluster1()` | `DongGuardian.entry()`API式限流 | DongGuardian |

#### ParrellServiceImpl
- **路径**: `server-demo-app/.../app/order/api/impl/ParrellServiceImpl.java`
- **依赖注入**: `@Qualifier("threadPoolExecutor")`, `@Qualifier("scheduledThreadPoolExecutor")`, `@Qualifier("threadPoolTaskExecutor")`

| 方法 | 功能 | 线程池类型 |
|------|------|-----------|
| `getFromThreadPool(name)` | submit任务到ThreadPoolExecutor | DongThread普通线程池 |
| `getFromScheduledThreadPool(name)` | schedule任务到ScheduledThreadPoolExecutor（延迟500μs） | DongThread调度线程池 |
| `getFromThreadPoolTask(name)` | submit任务到ThreadPoolTaskExecutor | DongThread Spring线程池 |

#### ItemServiceImpl
- **路径**: `server-demo-app/.../app/item/api/impl/ItemServiceImpl.java`
- **依赖**: `ItemDomainService`
- **方法**: `sayHello(param)` — 调用ItemDomainService.doSomething()，BO→DTO转换

#### OrderServiceHealthChecker
- **路径**: `server-demo-app/.../app/order/api/impl/OrderServiceHealthChecker.java`
- **实现**: `HealthChecker`接口（DongBoot Actuator）
- **方法**: `isHealthy()`返回UP，`getComponentName()`返回"DEMO-HEALTH-CHECKER"

#### App Converter

|--------|------|------|
| `OrderBOConverter` | BO→DTO | `convert(OrderBO→OrderDTO)` |
| `ItemBOConverter` | BO→DTO | `convert(ItemBO→ItemDTO)` |

### 3.6 Infra-Impl 基础设施实现层（server-demo-infra-impl）

#### OrderGatewayImpl
- **路径**: `server-demo-infra-impl/.../infra/order/gateway/impl/OrderGatewayImpl.java`

- **依赖**: `OrderMapper`, `jsfDemoConsumer(OrderService)`

| 方法 | 实现 | 数据源 |
|------|------|--------|
| `getByIdFromDb(orderId)` | `orderMapper.getById(orderId)` | MySQL via DongDAL |
| `getByIdFromRpc(orderId)` | `jsfDemoConsumer.getFromDb(new OrderParam(orderId))` → `OrderDTOConverter.convert()` | JSF RPC |

#### ItemGatewayImpl
- **路径**: `server-demo-infra-impl/.../infra/item/gateway/impl/ItemGatewayImpl.java`
- **方法**: `getById(itemId)` → `itemMapper.getById(itemId)`

| Mapper | SQL |
|--------|-----|
| `OrderMapper.getById(id)` | `SELECT * FROM \`order\` WHERE id = #{id}` |
| `ItemMapper.getById(id)` | `SELECT * FROM item WHERE sku_id = #{id}` |

## 四、端到端（End-to-End）业务链路追踪

### 4.1 链路一：HTTP → JSF RPC 查询订单

```
HTTP GET /order/getfromrpc?id=demo
  │
  ▼
OrderController.getOrderFromRpc(id)
  │  new OrderParam(id)
  ▼

  │  param.getId()
  ▼
OrderDomainService.getFromRpc(orderId)
  │
  ▼
OrderGateway.getByIdFromRpc(orderId)              ← OrderGateway接口
  │
  ▼
OrderGatewayImpl.getByIdFromRpc(orderId)          ← @BootReference JSF消费
  │  new OrderParam(orderId)
  │  jsfDemoConsumer.getFromDb(OrderParam)        ← 远程JSF调用
  ▼
[远程服务返回 OrderDTO]
  │
  ▼
OrderDTOConverter.convert(OrderDTO→OrderDO)       ← Infra层转换
  │
  ▼
OrderDOConverter.convert(OrderDO→OrderBO)         ← Domain层转换
  │
  ▼
OrderBOConverter.convert(OrderBO→OrderDTO)        ← App层转换
  │
  ▼
OrderDTOConverter.convert(OrderDTO→OrderVO)       ← Web层转换
  │
  ▼
Result<OrderVO> → HTTP Response
```

```
  DTO→VO: OrderDTOConverter.convert(OrderDTO→OrderVO)  [web层]
```
